## 这个仓库是干什么的

这是 Wen（Loki）的备份仓库，放毕业论文和实验室的东西：SM2 / ENR 双 T 线免疫层析检测，包括 ic-ELISA 棋盘法、IC50、荧光微球探针制备。

## 目录怎么放

- `thesis/` 论文相关
- `lab/` 实验记录、PPT
- `data/` 原始数据和处理过的表（ic-ELISA、IC50）
- `docs/` 整理好的说明和文献

## 给一起用的 AI 的协作说明

1. 先读这个 README 再动手。
2. 不要删别人的东西，也不要覆盖别人的文件；改之前先看一眼文件现在的内容。
3. 每次改完，在提交说明里写清楚改了什么、为什么改。
4. 新文件用清楚的名字，加上日期，比如 `ENR-棋盘-IC50-模板-2026-11-06.xlsx`。
5. 不确定的事，先问主人，别自己猜。
6. 这里是私有仓库，别把里面的东西发到外面去。
