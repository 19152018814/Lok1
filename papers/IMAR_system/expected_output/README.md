# Expected Output

This directory contains reference outputs for the demo run (`infer.py`) and
the batch test (`batch_test.py`).

| File | Description |
|------|-------------|
| `demo_run_reference.json` | Expected JSON output when running `infer.py` on the demo image pair (`demo_data/original.jpg` + `demo_data/background.jpg`) |

The `timestamp` field and exact numeric values will differ between runs; the
schema (keys and data types) should be identical.
