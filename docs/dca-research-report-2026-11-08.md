# 大学生小额长期定投（2026年11月）研究：适合定投的股票与ETF

> **本报告为公开信息研究整理，仅供学习参考，不构成投资建议。** 定投不能规避风险、不能保证收益，也不是储蓄的等价替代。所有价格与估值均标注来源与日期（截至2026年11月6日收盘为主，检索于2026年11月8日）；不同数据商的口径不同，同一指标出现分歧时本报告并列呈现，不强行取舍。投资前请到基金公司官网 / 交易所核验最新净值、费率、溢价与风险揭示书，并按自身风险承受能力决策。

## Summary（结论先行）

**截至2026年11月6日，市场正处在一次明显的调整之后：** A股沪深300自6月22日高点调整至11月3日，10月30日收盘3985.50点创2025年8月以来新低；11月6日沪深300报4054.28点（-1.44%），创业板指2465.23点（-3.96%），恒生指数24481.86点（-1.27%）；美股11月5日大跌（标普500 -4.36%、纳指 -5.52%），11月6日小幅反弹，纳指100已于11月2日进入技术性回调（较10月纪录高点跌10.4%）。

**估值上，A股大盘处于“中枢附近、谈不上极度低估”，创业板PE分位很低但PB仍高，科创50绝对PE极高；美股按预期盈利看不算极贵，但对盈利预测的依赖很重；恒生指数PE约10.8倍，处于历史中位附近。**

**给大学生的核心判断（研究结论，非建议）：**
1. **首选宽基指数ETF定投，而不是个股定投**——个股可能退市、暴雷、长期不回头，指数有成分股优胜劣汰机制。
2. **首选沪深300ETF作底仓**，辅以中证500 / 红利作搭配；创业板、科创50只适合能承受20–30%回撤的小仓位卫星。
3. **2026年11月最需要避的坑是QDII场内ETF的高溢价**：博时标普500ETF（513500）溢价10.82%、国泰纳指100ETF（513100）溢价高达21.14%（2026年11月5日估值），场内买入等于多付一成至两成的钱，溢价回落即亏损；场外联接按净值申购、没有溢价，但截至11月6日多数处于限购（每天10元）或暂停申购状态。
4. **金额与期限**：多份2026年指南的共识是每月拿收入的10%–20%、用3–5年以上不用的闲钱、坚持3–5年以上；不要用生活费、学费或短期要用的钱定投。

### 5. 定投通用指引

**为什么宽基指数通常优于个股（定投场景）：**
1. **分散与自动新陈代谢：** 指数是一篮子几十至上百家公司，单一公司暴雷对指数影响微乎其微；指数定期剔除衰落企业、纳入优质新股，长期跟随经济发展，不会出现退市归零。来源：https://stock.jrj.com.cn/2026/10/05074958615285.shtml（index）。
2. **成本与纪律：** 宽基ETF费率可低至0.15% + 0.05%/年，远低于主动基金；定投用固定金额、固定时间买入，低位买得多、高位买得少，摊平成本，避免情绪化追涨杀跌。
3. **长期向上是前提：** 定投的“微笑曲线”要求指数最终回到起投点之上并配合止盈纪律；如果市场十年不回来，定投只是均匀地亏。来源：https://alishangtian.com/article/user-635d19a04f（index）。

**定投不等于收益更高：** Vanguard对1976–2022年美股、英股、新兴市场等7个指数的滚动一年期回测显示，一次性投入在61.6%–73.7%的时期跑赢分批定投，平均领先约2个百分点——因为钱在市场里的时间越长，吃到上涨的概率越大。定投的价值主要在行为层面（减少焦虑、增强持有韧性），而非更高的预期收益。来源：同上（转引Vanguard研究）。

**金额与期限（多份2026年指南的共识）：**
- 每月拿收入的10%–20%定投，用3–5年不用的闲钱，至少坚持3–5年、穿越市场周期。来源：https://finance.publicdata.online/articles/2026-04-18-etf-investing-guide.html（index）；https://k.sina.cn/article_7879922977_1d5ae152101901a8nq.html（index）。
- 组合建议2–4只相关性较低的指数基金，例如沪深300（核心）+ 中证500（成长）+ 红利（防御）+ 恒生 / 标普500（境外分散），每年再平衡一次。来源：同上及FinTools角色配置框架（底仓60% / 现金流20% / 卫星≤20%）。
- 对学生而言：先留足3–6个月生活费应急，再定投；每月300–1000元量级优先用场外联接基金（起投门槛低、可自动扣款），场内ETF需按100股一手交易、单笔金额受股价限制。
