# 多糖结构解析 · KBr 压片 FTIR 一页操作清单

来源：刘军博士《多糖结构解析》课件（2025年9月），文件 `workspace/user/files/upload-2.pptx`，共 20 页。
实验步骤在第 IV 部分（P8–17）；本清单只写课件里的内容，需要实验室核对的数值留空，不编数。
注意：课件标题写“近红外”，实际方法是中红外 FTIR，4000–400 cm⁻¹（P1、P4）——写报告时按中红外写。

## 操作前核对
- [ ] KBr 为光谱纯；多糖样品、已知对照（如淀粉或葡聚糖）已备好（P7）
- [ ] 玛瑙研钵、药匙、模具清洁干燥；压片机、真空装置、FTIR 仪、透射片架正常（P7–P8）
- [ ] 记录本已备好：样品编号、干燥条件、称样量、KBr 用量、压片设置、扫描参数（P7）

## 1. 干燥与预处理（P8）
- [ ] KBr：按实验室规程干燥，参考条件约 110 ℃、2–3 h，冷却后放干燥器保存
- [ ] 多糖样品：按样品稳定性单独定干燥条件，不要照搬 KBr 的条件
- [ ] 粉末少暴露，取用后立即密封防返潮

## 2. 称量与研磨（P9）
- [ ] 起始比例示例：1 mg 多糖 + 100–200 mg 干燥 KBr，按模具容量和峰强调整；对比样品条件保持一致
- [ ] 先把样品研细，再加 KBr 充分混匀，以粉末细匀、无明显颗粒为准；别研太久（吸湿）
- [ ] 装模前确认模具清洁干燥；记录实际质量：样品 ____ mg，KBr ____ mg，模具直径 ____ mm

## 3. 压片（P10）
- [ ] 均匀铺粉；有真空功能的按规程排气
- [ ] 加压：用实验室已验证的载荷和保压时间（教师核对设置后再操作）；记录载荷 ____（单位 ____）、保压 ____、真空条件 ____
- [ ] 缓慢卸压取片；洁净工具夹片缘，别碰片面；及时放入透射样品架

## 4. 压片质量检查（P11）——不合格就重新制片，别硬测
- [ ] 均匀透亮 → 合格，及时测定，并检查吸收峰是否饱和
- [ ] 发白 / 有颗粒 → 受潮或颗粒粗：重新干燥、细研混匀
- [ ] 开裂 / 易碎 → 核对模具装配和卸压程序
- [ ] 强峰截顶 / 透过率过低 → 降低样品比例或减少装样量
- [ ] 异常谱图保留着用于分析

## 5. 背景与采集（P12、P15–16）
- [ ] 透射模式，装压片架；软件确认仪器连接和光学台状态正常
- [ ] 背景：同批干燥 KBr 的空白片，参数与样品一致
- [ ] 样品参数：范围 4000–400 cm⁻¹，分辨率 4 cm⁻¹，累加扫描 32 次（可按信噪比增加）
- [ ] 背景采完尽快测样，减少水蒸气和 CO₂ 变化的影响

## 6. 重复性与干扰（P13）
- [ ] 每组独立制片 3 片；同一片多次扫描不能替代独立制片，两个次数分开记录
- [ ] 留意干扰峰：约 1640 cm⁻¹（结合水）、约 1740 cm⁻¹（酯基或质子化羧基）、约 1600 与 1410 cm⁻¹（羧酸盐成对吸收）——结合干燥前后及空白谱图判断，别直接归属

## 7. 保存与数据处理（P14、P17）
- [ ] 同时保存仪器原始文件和 CSV 数据；文件名含样品编号、制片序号、日期
- [ ] 先查基线、噪声、水分干扰，再做必要的基线校正；样品间平滑、归一化方法一致
- [ ] 标峰比较：全谱 + 指纹区（1200–800 cm⁻¹），记录峰位、峰形、相对强度；不预设峰数强制分峰

## 实验报告用段落（可直接贴，改数字即可）
> 本实验采用溴化钾压片透射法进行多糖的中红外傅里叶变换红外光谱（FTIR）测定。光谱纯 KBr 按实验室规程干燥（参考条件约 110 ℃、2–3 h），冷却后置干燥器保存；多糖样品按其稳定性单独确定干燥条件。将多糖样品与干燥 KBr 混合（起始比例示例为 1 mg 样品与 100–200 mg KBr），研细混匀后装模压片，压片载荷与保压时间采用实验室已验证的条件，缓慢卸压取片。每组独立制片 3 片，以同批干燥 KBr 空白片采集背景，透射模式下扫描范围 4000–400 cm⁻¹，分辨率 4 cm⁻¹，累加扫描 32 次。原始数据与 CSV 数据同时保存，文件名包含样品编号、制片序号和日期；数据处理时先检查基线、噪声及水分干扰，样品间采用一致的基线校正、平滑与归一化方法，在全谱及指纹区（1200–800 cm⁻¹）内比较峰位、峰形与相对强度。
>
> 注意：段落里的载荷、保压时间、实际称量、模具直径等数字课件里没有给，填你实验记录里的实测值再交；FTIR 只能做官能团识别与谱图比较，完整结构还需单糖组成、甲基化分析及 NMR 等证据（P4、P18）。
